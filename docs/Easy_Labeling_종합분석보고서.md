## 🎯 1. 프로그램 개요

### 1.1 프로그램 정의
Easy Labeling은 **객체 탐지(Object Detection)를 위한 이미지 어노테이션 도구**로, YOLO 포맷의 바운딩 박스 레이블링에 특화된 웹 기반 애플리케이션입니다.

### 1.2 핵심 특징
- **Local-First 아키텍처**: 서버 없이 브라우저에서 완전 동작
- **File System Access API 활용**: 로컬 파일 직접 접근 (업로드 불필요)
- **YOLO 표준 지원**: 컴퓨터 비전 업계 표준 형식 완벽 호환
- **실시간 협업 UI**: 직관적인 드래그 앤 드롭 인터페이스

### 1.3 주요 기능
| 기능 분류 | 세부 기능 | 혁신성 |
|-----------|-----------|---------|
| **이미지 관리** | JPG, PNG, TIFF 지원 + 폴더 단위 로드 | ⭐⭐⭐ |
| **바운딩 박스 편집** | Fabric.js 기반 직관적 드래그 앤 드롭 | ⭐⭐⭐⭐ |
| **클래스 레이블링** | YAML 파일 기반 클래스 정의 시스템 | ⭐⭐⭐⭐ |
| **데이터 포맷** | YOLO 형식 저장/로드 | ⭐⭐⭐⭐⭐ |
| **사용자 경험** | 다크모드, 자동저장, 키보드 단축키 | ⭐⭐⭐⭐⭐ |

## 🏗️ 2. 개발 배경 및 목적

### 2.1 개발 동기
**문제 인식**: 기존 이미지 라벨링 도구들의 한계
- 클라우드 의존성으로 인한 데이터 프라이버시 우려
- 복잡한 설치 과정 및 서버 설정 필요
- 고비용 구조 (SaaS 모델, 라이선스 비용)
- 네트워크 연결 필수 (오프라인 작업 불가)

### 2.2 해결 방안
**"Local-First AI Tooling" 패러다임 도입**
```
전통적 접근 방식: Client ↔ Server ↔ Cloud Storage
혁신적 접근 방식: Browser → File System Access API → Local Storage
```

### 2.3 설계 철학
1. **프라이버시 우선**: 데이터가 로컬 환경을 벗어나지 않음
2. **접근성 극대화**: 브라우저만으로 즉시 사용 가능
3. **표준 호환성**: YOLO, YAML 등 업계 표준 완벽 지원
4. **사용자 중심**: 직관적 UX로 학습 곡선 최소화

### 2.4 개발 연혁 (WORKLOG.md 기반)

## 🚀 6. 혁신성 및 기술적 우수성

### 6.1 아키텍처 혁신
**Paradigm Shift: Server-Side → Client-Side**
```
Traditional Architecture:
Browser → API Gateway → Microservices → Database → File Storage

Easy Labeling Architecture:
Browser → File System Access API → Local Storage
```

**장점**:
- 레이턴시 제로 (네트워크 지연 없음)
- 무한 확장성 (사용자 기기 성능에 비례)
- 장애 포인트 최소화 (서버 다운타임 없음)

- **Fabric.js**: 고성능 캔버스 조작

- **CSS Custom Properties**: 동적 테마 시스템
- **ES6+ JavaScript**: 모던 언어 기능

**TypeScript 마이그레이션 진행 중**
