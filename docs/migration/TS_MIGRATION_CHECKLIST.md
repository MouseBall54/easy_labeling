# Easy Labeling TS 마이그레이션 작업 단계 & 체크리스트

> 참고: `docs/ts-migration-status.md`의 현황 분석을 바탕으로 작성한 실행 계획입니다. 각 단계는 선행 단계 완료를 전제로 하며, 체크박스를 통해 진행도를 추적할 수 있습니다.

---

## Phase 1. 코어 통합 복구
- 목표: TS 리팩토링된 모듈 간 의존성/이벤트 연결을 복구하여 기본 워크플로가 동작하도록 함.
- 체크리스트
  - [x] `App.setupCrossReferences`에서 UIManager ↔ EventManager ↔ CanvasController 간 이벤트 구독·콜백을 명시적으로 설정한다.
  - [x] `AppState` 이벤트 명(`image:current-changed` 등)과 `App`/UIManager에서 구독하는 이벤트 명을 통일한다.
  - [x] 캔버스 `object:*` 이벤트를 UIManager/앱 상태에 전달하여 라벨 패널 및 상태가 업데이트되도록 연결한다.
  - [x] EventManager의 이미지 네비게이션(단축키/좌우 버튼)과 UIManager 이미지 리스트 하이라이트가 동기화되도록 한다.

## Phase 2. 라벨 & 클래스 워크플로
- 목표: 클래스 정의 로딩/선택 및 라벨 관리 기능을 복원.
- 체크리스트
  - [ ] `FileSystemService.listClassFiles`와 클래스 YAML 파서를 UIManager에서 호출하여 드롭다운을 채운다.
  - [ ] 클래스 선택 모달(`labelClassModal`) 오픈/저장 로직을 구현하고, 새 박스 생성 시 클래스 ID 입력 경로를 연결한다.
  - [ ] 컨텍스트 메뉴 및 버튼을 통해 라벨 클래스 변경·삭제 기능을 동작하게 한다.
  - [ ] `updateLabelList`를 캔버스/이벤트와 연동해 라벨 패널이 항상 최신 상태를 반영하도록 한다.
  - [ ] `AppState.classNames`를 이용해 클래스 이름이 캔버스 라벨 및 리스트에 표시되도록 한다.

## Phase 3. 탐색/필터 UX
- 목표: 이미지 탐색 관련 생산성 기능을 복원.
- 체크리스트
  - [ ] 이미지 검색 입력 및 라벨 여부 필터 토글 이벤트를 구현하고 `renderImageList`에 적용한다.
  - [ ] 미리보기 바(썸네일 캐싱, 좌우 스크롤/선택) 렌더링 로직을 추가한다.
  - [ ] 키보드 단축키(`A/D`, `Ctrl+Q` 등)와 UI 상태가 일관되게 반응하도록 보완한다.
  - [ ] UIManager의 필터 버튼/정렬 버튼이 실제 라벨 리스트를 필터링/정렬하도록 구현한다.

## Phase 4. 저장 & 상태 지속성
- 목표: 자동 저장 및 라벨 상태 추적을 복구하여 데이터 손실 위험 제거.
- 체크리스트
  - [ ] `AppState.isAutoSaveEnabled` 플래그가 true일 때 캔버스 변경 이벤트에서 자동으로 `saveLabels`를 호출한다.
  - [ ] 라벨 저장 성공 시 `AppState.setImageLabelStatus`를 업데이트하고 UI에 라벨 상태 뱃지가 반영되도록 한다.
  - [ ] TIFF 포함 이미지 로드/저장 경로를 실제로 검증하고 에러 처리 토스트를 보완한다.
  - [ ] 저장 실패/권한 거부 시 재시도 안내 및 상태 롤백 처리를 구현한다.

## Phase 5. QA & 마감 정리
- 목표: 기능 검증 및 문서/배포 준비.
- 체크리스트
  - [ ] 주요 사용자 흐름(폴더 선택 → 라벨링 → 저장 → 재로드)을 시나리오별로 수동 테스트한다.
  - [ ] 테스트 시나리오 및 확인 결과를 `docs/migration` 내 테스트 노트로 남긴다.
  - [ ] 새/변경된 단축키 및 기능 설명을 사용자용 README에 반영한다.
  - [ ] 번들 빌드 및 브라우저 스모크 테스트(Chrome, Edge) 결과를 기록한다.
  - [ ] 필요 시 1회분 QA용 태스크 또는 자동화 스크립트(npm script 등)를 준비한다.

---

### 사용 방법
1. 각 Phase를 순서대로 진행하되, 상황에 따라 병렬 작업이 가능한 항목은 병행해도 무방합니다.
2. 항목 완료 시 체크박스를 표시하고, 세부 작업 노트는 `docs/migration/WORKLOG.md` 또는 별도 문서에 남깁니다.
3. 단계 완료 후 `docs/ts-migration-status.md`를 갱신하여 최신 구현 현황을 유지합니다.
